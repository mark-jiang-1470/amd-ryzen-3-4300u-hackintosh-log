# 配置改动：原始、当前与公开版

基准为本机最初可启动的 U 盘 EFI；当前版本为 2026-10-28 从实际内置 EFI 只读读取的文件，源 config 哈希与最后安装收据一致。下文不公开原始身份字段或完整私有配置。

## 原始 EFI → 当前实际 EFI

| 项目/路径 | 原值或原状态 | 当前值或改动 | 用途与核验边界 |
|---|---|---|---|
| OpenCore.efi / BOOTx64 / OpenRuntime | 原有 1.0.9 DEBUG 构建 | 保留同构建文件 | 没有借显示修复升级整套引导 |
| OpenCanopy.efi | 无 | 增加同构建驱动，UEFI/Drivers 启用 | 图形启动菜单；避免混装其他构建 |
| Misc/Boot/PickerMode | Builtin | External | 使用 OpenCanopy |
| PickerVariant | Auto | Local\LogoGlow | 黑底 Logo 轮廓描光；由原扁平图标主题改造 |
| PickerAttributes | 17 | 144 | 当前图标/选择器显示设置 |
| Timeout / ShowPicker | 5 / true | 0 / true | 停留菜单等待手动确认，不倒计时自动启动 |
| HideAuxiliary | false | true | 隐藏恢复等辅助项，空格展开 |
| LauncherOption | Disabled | Full | 内置 OpenCore 启动入口注册设置；文件存在不能证明 BIOS 默认顺序已验证 |
| itlwm.kext | 启用 2.3.0 | 停用 | 从旧 Wi-Fi 方案切换，避免与 AirportItlwm 同时加载 |
| AirportItlwm.kext | 未配置 | 增加 2.4.0 alpha，Darwin 25.0.0–25.99.99 | Tahoe 系统原生 Wi-Fi；不是所有系统通用 |
| NootedRed.kext | 0.8.10 | 替换为 pre-release.11，内部版本 0.9.0 | 用于远控频闪、窗口跳动显示修复实验；未开启实验视频硬解 |
| NVRAM/Add/.../boot-args | 原参数 | 追加 `-NRedDisplayFix` | 配合该实验驱动；其他原参数保留 |
| SMCProcessorAMD.kext | 未配置 | 增加 1.0.1，Darwin 25.x | CPU 温度/包功耗，加载及连续读数已观察 |

| Windows 引导 | 内置既有 Microsoft 文件 | 当时迁移核验保持不变 | 公开包不携带个人 Windows BCD/启动目录 |

当前完整 boot-args：

```text
-v debug=0x100 keepsyms=1 -ibtcompatbeta revpatch=sbvmm e1000=0 -NRedDisplayFix
```

只有 `-NRedDisplayFix` 是本次显示修复追加的参数；其余是继承基线。`-v` 和调试参数用于排障；蓝牙/RestrictEvents/网卡参数是否保留，应结合各自上游文档和目标系统判断，不能把这串参数当作所有 AMD 机器的默认值。

## 当前配置中继承、未盲改的关键项

- **AMD 补丁**：27 项，24 项启用；包含物理核心数、CPUID、时间、PCIe 与 PAT 相关补丁。四处核心数常量当前为 4；详见 [逐项明细](AMD内核补丁.md)。不同内核版本由 MinKernel/MaxKernel 选择，不应删除看似重复的版本分支。
- **Kernel**：`ProvideCurrentCpuInfo=true`、`DummyPowerManagement=true`、`DisableIoMapper=true`、`XhciPortLimit=false`，没有借传感器安装接管 CPU 调频。
- **Booter**：保留原有内存映射组合，含 `DevirtualiseMmio=true`、`EnableWriteUnprotector=true`、`SetupVirtualMap=true`、`RebuildAppleMemoryMap=false`。这不是给其他主板的调参建议。
- **MMIO 白名单**：`0xF0000000`、`0xFD000000`、`0xFEE00000`、`0xFEE01000`，来自本机历史引导观察；不同 BIOS/主板必须重新核实。
- **ACPI**：保留 `SSDT-EC.aml`、`SSDT-PLUG-ALT.aml`、`SSDT-USB-Reset.aml`、`SSDT-USBX.aml`；ACPI/Patch 和 Delete 当前为空。USB Reset 引用了 `_SB.PCI0.GP17.XHC0/1.RHUB` 路径；路径不匹配时不能照搬。PLUG-ALT 的存在不代表 Intel XCPM 电源管理适用于 AMD。
- **APFS**：`EnableJumpstart=false`，使用现有 `apfs_aligned.efi`；不要在没有救援入口的情况下删除现有文件系统驱动。
- **机型与安全设置**：MacPro7,1；`SecureBootModel=Disabled`、`Vault=Optional`、`csr-active-config=03000000`。这是参考机当前配置记录，不等同于原生 Mac 默认安全配置；本次显示/传感器维护没有修改这些项。
- **调试**：DEBUG OpenCore，`AppleDebug=true`、`ApplePanic=true`、`Target=67`、`SysReport=false`、`ExposeSensitiveData=7`。运行后可能在本地写调试日志，分享前需脱敏；发布包不携带原日志。

## 实际 EFI → 公开副本

1. 清空 `PlatformInfo/Generic` 的 SystemSerialNumber、MLB，SystemUUID 改为全零占位，ROM 改为 6 字节零。每位使用者须自行生成/填写。
2. 移除 NVRAM/Add 中两个蓝牙控制器缓存字段；保留相应 Delete 键名称以免沿用旧缓存。未公开设备地址或控制器身份缓存。
3. 清空启动密码哈希/盐；参考配置本身未启用启动密码。
4. 不复制 `EFI/Microsoft`、`EFI/APPLE`、所有旧 config、旧驱动备份、NVRAM 转储、启动日志、分区根目录隐藏数据。
5. 只打包启用的驱动；停用的 itlwm 和另一份未引用的 AppleIGC 不打包，配置中的停用记录保留。
6. **唯一与上述脱敏不同的驱动调整**：`CtlnaAHCIPort.kext` 在原机为启用，公开副本改为禁用并省略该旧 Apple AHCI 补丁二进制。当前机器使用 NVMe，未证明需要它；其来源许可未确认，不能把它改标 GPL。没有在原机移除或禁用。
7. 修正公开 config 内 NootedRed 的过时说明注释，使其与实际 0.9.0/pre11 文件相符；不改变其加载顺序或版本限制。

公开副本已经通过 `ocvalidate` 和文件引用校验，**尚未实盘启动测试**。从当前可用 EFI 导出，不代表清空身份和省略旧 AHCI 后可以跳过个人适配。校验哈希记录公开副本本身，不包含私有源 config 的哈希。
