# 脱敏范围与许可

本项目自编的配置整理、文档及辅助工具采用 **GNU GPL version 3（GPL-3.0-only）**。根目录 LICENSE 是完整许可证文本。EFI 内第三方驱动、引导、图标及 ACPI 的权利归原作者，其原许可证不因本项目的 GPL 声明而改变。

## 没有公开的内容

- SMBIOS SystemSerialNumber、MLB、SystemUUID、ROM 的原始值。
- 蓝牙控制器缓存、个人设备地址、附近设备名称、Wi-Fi 密码和账号。
- Windows Microsoft 引导/BCD、APPLE 私有目录、NVRAM 转储、启动日志、panic、安装收据。
- config 的历史备份、旧 NootedRed、未使用的 AppleIGC、个人磁盘 UUID、SSD 序列号和本机目录用户名。

公开配置的身份项留空/全零；仅改公共副本，没有修改正在使用的 EFI。原始完整 EFI、个人数据和备份仍在本机，GitHub 无法恢复它们。
