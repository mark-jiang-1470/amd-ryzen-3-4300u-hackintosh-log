2026-10-28 从实际内置 EFI 读取版本和 Enabled 状态；“原机启用”表示配置设置，不等于全部功能场景验收。机器可读清单见 [驱动清单.json](驱动清单.json)，文件哈希见根目录 `EFI-SHA256.json`。

## UEFI 驱动

| 文件 | 作用 | 配套关系 |
|---|---|---|
| OpenRuntime.efi | 运行时服务兼容 | 当前 OpenCore 同构建 |
| OpenCanopy.efi | 图形启动选择器 | 本次增加的同构建文件，不混用其他 OpenCore 版本 |
| HfsPlus.efi | HFS+ 文件系统读取 | 继承原 EFI；[OcBinaryData](https://github.com/acidanthera/OcBinaryData/tree/master/Drivers) |
| apfs_aligned.efi | 当前 APFS 读取方案 | 继承原 EFI，同时 `EnableJumpstart=false` |
| ResetNvramEntry.efi | NVRAM 重置辅助入口 | 同构建；无需每次启动都清 NVRAM |

OpenCore / BOOTx64 / OpenRuntime 保持原有 1.0.9 DEBUG 构建，标识 DBG-109-2026-10-23，准备包来自 build-repo `78d5ff8`。这不是用“最新版”拼出的新 EFI。验证器需为对应 1.0.9。

## 其他人应当装什么

- 相近 AMD Renoir 平台基础为 OpenCore、适用的 AMD 内核补丁、Lilu、VirtualSMC、NootedRed；仍需核对核心数、BIOS、ACPI 和显卡支持范围。
- AX210 的 Wi-Fi 与蓝牙分别按目标系统选择驱动。本包 AirportItlwm 只针对 Tahoe，不适用于任意 macOS。启用固件不代表 AirDrop 可用。
- I226-V 使用对应 AppleIGC；换 Realtek 等网卡必须换驱动，不应把本机有线配置照搬。
- SMCProcessorAMD 是可选监测插件，不是 `SMCAMDProcessor`；无需为了读温度再安装 AMDRyzenCPUPowerManagement。
- 没有配置 AppleALC、VoodooI2C、VoodooPS2、电池插件或 WhateverGreen。不能在音频 codec、触控板和电池硬件未核实时盲装这些驱动；本配置也未把笔记本电池功能验收为可用。
- NootedRed 不与 WhateverGreen 同时启用；同一个网卡不要同时启用两个驱动版本。USB 完成专用映射后再替换 UTBDefault。

## 网络故障仍需观察

参考机存在过 `m->m_flags & M_PKTHDR` 网络断言。AppleIGC 上游有 [同版本 1.8d1 相同断言报告](https://github.com/SongXiaoXi/AppleIGC/issues/35)，硬件环境不同，不能据此证明本机唯一根因；也不能只因曾连接 Wi-Fi 就排除有线驱动。复现时应分别隔离有线、Wi-Fi、代理与远控路径。
