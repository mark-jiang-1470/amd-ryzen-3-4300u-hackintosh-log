## 系统信息里的伪装

`PlatformInfo/Generic/SystemProductName=MacPro7,1` 是 OpenCore SMBIOS 设置。macOS 的 Mac Pro、Intel Core i5、部分 PCIe 宽度等显示不应直接视为真实整机规格。真实 CPU 以 CPUID/品牌字符串和硬件为准。`revcpu=1`、`revcpuname=AMD Ryzen 3 4300U` 等显示兼容参数也不代表在更改物理硬件。

当前软件环境：macOS 26.7.2 / build 25G332、Darwin 25.6.0、x86_64；OpenCore 1.0.9 DEBUG。只对这个组合有本次观察，不把支持范围扩大到其他 BIOS、其他 Ryzen 型号或所有 macOS 版本。
